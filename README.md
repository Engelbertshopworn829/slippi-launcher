## 🛠️ Troubleshooting Common Issues

If the software fails to open, verify that you have the latest system updates for Windows. Sometimes antivirus programs flag the emulator by mistake. If the program hangs, check your security settings to ensure the application has permission to access the network.

If the game runs with visual errors, open the "Graphics" menu in the settings. Ensure that the backend is set to "Direct3D 11" or "Vulkan". These settings offer the best compatibility with modern hardware.

If the controller inputs do not register, plug in your controller before you launch the game. Use the "Controllers" menu to bind your buttons if the default setup does not feel right.
