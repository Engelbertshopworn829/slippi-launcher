## Overview
**Slippi Launcher** is the official launcher for **Slippi**, the premier online experience for Super Smash Bros. Melee.
It provides smooth netplay, replay management, mod support, and an improved gameplay experience for the legendary fighting game.


<img width="1230" height="887" alt="image" src="https://github.com/user-attachments/assets/e59c9143-b1f8-45e1-97c7-89ac3c0d82cf" />


## Key Features
- Low-latency online Netplay
- Built-in Replay Viewer & Analyzer
- Easy mod management (Slippi Mods)
- Automatic updates
- Fast matchmaking
- 60FPS support & rollback netcode
- Dolphin integration
- Clean and modern interface

## How to Use
1. Download the latest release
2. Extract the archive
3. Run `Slippi Launcher.exe`
4. Log in or create a Slippi account
5. Choose Play Online or launch local game
6. Enjoy Melee with modern netplay!
